# Волинська приватна автошкола — концепт сайту

> **Статус: неофіційний демо-концепт.** Не є офіційним сайтом автошколи і не пов'язаний з нею.
> Логотип, фото й тексти взято з публічної сторінки https://www.facebook.com/volynprivatavtoschool лише для демонстрації;
> права належать їхнім власникам. Архівне фото використано як ілюстрацію.
>
> Демо-захист: плашка зверху + дисклеймер у футері, `noindex`, `robots.txt`, `demo: true` у `config.js`
> (форма нічого не надсилає й не зберігає), у блоці відгуків — заглушка замість вигаданих відгуків.

Статичний сайт (HTML/CSS/JS, без збірки). Локально: `node serve.js` → http://localhost:5181

## Що всередині
- line-art авто, яке «малюється» при завантаженні, з фарами, що вмикаються;
- картки категорій A/B/C/E у вигляді дорожніх знаків, що перевертаються;
- контраварійне та екстремальне водіння з анімованим заносом;
- горизонтальна прокрутка переваг дистанційного курсу;
- міні-тест з ПДР (3 питання з поясненнями);
- повзунок «тоді / зараз»;
- форма запису (кілька послуг, маска телефону, валідація);
- відгуки та рейтинг з Google Maps (у робочій версії).

## Запуск як офіційного сайту (після погодження з автошколою)
1. `backend/Code.gs` → Google Apps Script, Script Properties: `NOTIFY_EMAIL`, `TG_BOT_TOKEN`/`TG_CHAT_ID` (опційно), `PLACES_API_KEY`, `PLACE_ID`; Deploy → Web app (Anyone).
2. `config.js`: `demo: false`, `backendUrl: "<URL>"`.
3. Прибрати `.demo`, `.form__demo`, `.foot__disc`, мета-тег `robots` і `robots.txt`.
4. Додати адресу, ціни, політику конфіденційності.
